An io game is a simple, fast arcade game where many players share one arena, usually trying to grow bigger or survive longest, with very short rounds and one-touch controls. The name comes from Agar.io (2015), a browser game that used the .io web address ending; later games copied the name and the style.

Where does the name ".io" come from?

".io" is a website address ending, like .com. Agar.io used it in 2015, became a huge hit, and many games that followed (Slither.io, Diep.io, Paper.io, Hole.io) used the same ending. Over time ".io" became a sign for this family of simple grow-and-survive games.
