Will Gobbly.io run on my phone?

Last updated 2026-11-17

Gobbly.io runs on iPhone with iOS 15 or newer and on phones with Android 7.0 or newer. The download is about 90 MB. If the store shows the game for your phone, your phone is supported.

Is it on iPhone?

Yes: Gobbly.io on the App Store. It is made for iPhone.

Does it run on older phones?

Yes. The game adjusts its graphics to the phone: phones with less memory get simpler shadows so the game stays smooth. If it still feels slow, close other apps, turn off battery saver and restart the phone.

Does it drain the battery?

Like any 3D game, it uses more battery than reading. Short levels help, and lowering screen brightness saves the most.

Where is the safe place to download it?

Only from the official stores: App Store and Google Play. Copies on APK websites, "mod" and "unlimited coins" versions are not made by us and can contain malware.
