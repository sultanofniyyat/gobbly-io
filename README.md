# Gobbly.io website

Question-and-answer website for Gobbly.io (iPhone and Android), made for Google and AI assistants.
Live at https://sultanofniyyat.github.io/gobbly-io/

- Facts about the game: `site.json` (change a fact here once and every page updates)
- Pages: `content/` · Styles and pictures: `static/`
- Build: `python3 build.py` → `docs/` (served by GitHub Pages). Then commit and push.
- Keep every answer true for the real game. When the game changes (ads, prices, cloud save), update `site.json`, rebuild, push.
